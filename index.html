What is Brevity?

Append a number in brackets to any text layer name (like Headline [50]) and Brevity counts the characters, color-codes the status, and helps you fix anything over the limit without leaving the plugin.

Works with frames, components, instances, groups, and sections. Supports dark mode and meets WCAG AA contrast throughout.

Core auditing is free. Pro tools are available by subscription.

Features

Character auditing

Scan every text layer in a frame, component, group, or section and see counts at a glance.

Set character limits

Add [N] to any layer name to set a maximum. Brevity flags each layer as good, close, or over.

Summary dashboard

Status tiles show totals for within-limit, near-limit, and over-limit layers at a glance.

Click-to-zoom

Click any row to jump straight to that layer on canvas and select it.

Search & filter

Filter the layer list by name and find the text you need instantly.

Configurable options

Toggle space counting or include hidden layers to match your workflow.

Hidden layer detection

Spot hidden text layers at a glance and choose to include or exclude them.

Live sync

Counts update in real time as you edit text on canvas. No re-running needed.
